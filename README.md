# **SauceDemo E-commerce Automation using Selenium (Python)**

## **📌 Project Overview**
This project automates an end-to-end e-commerce workflow on the **SauceDemo website** using Selenium WebDriver in Python.

The automation covers the complete user journey from **login → product selection → cart → checkout → order confirmation**.

---

## **🚀 End-to-End Workflow Automated**

### **1. Login Page**
- Enter valid username and password
- Authenticate user successfully

---

### **2. Product Sorting**
- Apply filter: **Price (low to high)**

---

### **3. Product Selection**
- Iterate through product list
- Select **“Sauce Labs Fleece Jacket”**
- Navigate to product details page

---

### **4. Add to Cart**
- Add selected product to cart

---

### **5. Cart & Checkout**
- Navigate to cart page
- Proceed to checkout

---

### **6. Checkout Information**
- Enter user details:
  - First Name
  - Last Name
  - Postal Code

---

### **7. Order Completion**
- Finish order process
- Validate success message:
  - **"Thank you for your order!"**

---

## **🛠️ Technologies Used**
- Python
- Selenium WebDriver
